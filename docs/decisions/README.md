# Decisions

This directory is the authored decision source for aoa-pinterest-connector.

IDs use AOA-PINTEREST-D-NNNN. A decision is immutable after acceptance except for
status metadata or an explicit superseding decision. Keep context, alternatives,
rationale, consequences, source surfaces, and effect authority in every record.
